# Krea2 Concept Sliders

Product repo for **jimmycarter/krea2-turbo-bbox** particle sliders — parallel to [supra-concept-sliders](https://github.com/HyperGAN/supra-concept-sliders) and [anima-particle-sliders](https://github.com/HyperGAN/anima-particle-sliders).

Base model: [jimmycarter/krea2-turbo-bbox](https://huggingface.co/jimmycarter/krea2-turbo-bbox) (Krea-2 turbo transformer with bbox grounding DSL).

Scaffolding in progress. Train/infer backend will live in [HyperGAN/particle-sliders](https://github.com/HyperGAN/particle-sliders).
