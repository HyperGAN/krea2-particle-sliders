# Krea 2 rank-8 distillation and alpha calibration

The original Final Boss and Eldritch adapters are ordinary rank-16 attention
LoRAs. Unlike the Anima release, this release has no nonlinear particle teacher.
Its distillation compresses each trained linear branch to rank 8 using real
teacher activations. It does not accelerate the diffusion schedule: the bbox
base still uses 8 steps, guidance 0, and the distilled shift mu=1.15.

For an original branch `B A x`, capture `h = A x` and accumulate `G = sum(h hᵀ)`.
With thin QR `B = Q R`, diagonalize the small output covariance `R G Rᵀ`.
Its eight leading eigenvectors give an output basis `P = Q U₈`. The student
factors are `B₈ = P`, `A₈ = Pᵀ B A`, with a subsequent factor rescaling that
balances magnitudes without changing the product. This minimizes captured
output reconstruction error among rank-8 linear projections of the teacher.
No new bias, router, or activation is introduced.

Capture uses the six original training captions, both cached trajectory seeds,
and positions 0, 2, 4, 6 and 7 from each 8-step trajectory: 60 states. Each
projection contributes eight evenly spaced token inputs per state, or 480
activations. The teacher runs at its selected release alpha throughout capture.

Two separate development captions—a forest-gate traveler and a space-station
guard—supply all eight positions of frozen neutral trajectories at seeds 77001
and 77002. These captions are excluded from fitting. Development diagnostics
report both projection-relative error and the complete denoiser edit error
`v_student - v_base` against `v_original - v_base`. These are approximation
measurements, not image-quality scores or a final-test benchmark.

Original Final Boss uses alpha 16 at rank 16. Original Eldritch uses alpha 24
at rank 16, so nominal strength 1 matches the previously selected strength 1.5.
The original learned matrices are unchanged. Students begin with the same
alpha/rank gain and test multipliers 0.75, 1, 1.25, 1.5 and 2 on the development
states. The lowest complete-edit MSE selects the student's embedded alpha.
The release includes every candidate measurement and matched image comparisons.

Diffusers files embed `lora_adapter_metadata`; PEFT folders carry alpha in
`adapter_config.json`. ComfyUI files carry scalar `.alpha` tensors alongside
native Krea projection names. Strength 1 needs no separate user multiplier.
The source originals and all derived exports are immutable; reruns refuse to
replace an existing export with different weights or metadata.

```bash
CUDA_VISIBLE_DEVICES=0 python release_tools/distill.py
CUDA_VISIBLE_DEVICES='' python release_tools/verify_comfy.py \
  /path/to/ComfyUI artifacts/release
python release_tools/build.py
python release_tools/publish.py --folder artifacts/release
python release_tools/publish.py --folder artifacts/release --publish
```

Use the CUDA environment recorded by the training runs. Distillation records
are staged under `artifacts/release/evidence/`; the temporary capture and alpha
sweep outputs stay under `outputs/release-work/`. Publication includes model
cards, both formats, PEFT folders, matched Original/Distill/Off images, license,
source provenance and hashes. Raw training caches and logs are not uploaded.

The ComfyUI audit checks the real 28-block Krea topology, all 128 projection
mappings, patched weight deltas, alpha, clone isolation, and strength-zero
bypass. It is a CPU integration audit, not a full ComfyUI GPU image render.
Images are generated by the actual exported Diffusers files at strength 1.

The six original Off comparisons replay the earlier base renders pixel-for-pixel. Historical
PEFT previews and the released original-adapter previews differ slightly
(mean absolute pixel error 2.50–3.49 on the 0–255 scale). The native Diffusers
loader uses bfloat16 adapters with this base, whereas the earlier PEFT preview
path retained float32 adapters. Stored original matrices and alpha/rank gains
are verified exactly; cross-loader pixel equality is not claimed. The release
comparisons consistently use the same native Diffusers loading path.

`CUDA_VISIBLE_DEVICES=0 python release_tools/refresh_preview.py` renders the
additional street-photograph comparison at seed 4242 and makes it Final Boss's
featured case. It uses the published Original and Distill files at strength 1
and the adapter-disabled base at strength 0. Run `release_tools/build.py` afterward
to update the cards and comparison image. The earlier comparisons remain available.
